# FPS Booster 🚀

**FPS Booster** is a lightweight tool that improves your gaming experience by closing unnecessary background processes with a single click. Free up valuable system resources to boost your FPS and enjoy smoother, lag-free gameplay.

## Features

- ⚡ **One-Click Performance Boost**: Instantly close background processes that slow down your system.
- 🧹 **Resource Optimization**: Free up CPU and memory for better performance.
- 🎮 **Smooth Gaming Experience**: Enjoy faster, lag-free gameplay with minimal setup.

## How to Use

1. Download and install **FPS Booster**.
2. Launch the application.
3. Click the "Boost" button to close unnecessary background processes.
4. Enjoy enhanced FPS and smoother gameplay!

## Requirements

- Windows 10 or later
- 2GB RAM minimum
- 1.0 GHz processor minimum
